# 🚀 Chiru Chandan — Developer Portfolio Website

A modern, high-performance, interactive **Developer Portfolio Website** built with **React**, **TypeScript**, **Three.js**, **GSAP**, and **Vite**.

Designed to showcase backend microservices, software engineering projects, technical skillsets, and interactive design.

---

## ✨ Features

- **Interactive 3D / WebGL Experience** powered by Three.js
- **Dynamic Glassmorphic Project Cards** featuring backend microservice architectures
- **Smooth Animations** powered by GSAP and Lenis
- **Interactive Tech Stack Marquee** displaying modern engineering tools
- **Direct PDF Resume Download** (`ChiruCV.pdf`)
- **Fully Responsive & Clean Dark Mode Interface**

---

## 🧰 Tech Stack

- **Frontend:** React, TypeScript, HTML5, CSS3, JavaScript
- **3D & Animation:** Three.js, WebGL, GSAP, Lenis
- **Build Tool:** Vite
- **Icons:** React Icons, DevIcons

---

## 🛠️ Local Development

### 1. Clone the repository
```bash
git clone https://github.com/Chiru-5/portfolio-website.git
cd portfolio-website
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
